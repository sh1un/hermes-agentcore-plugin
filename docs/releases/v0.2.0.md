# v0.2.0

Hermes can now use Amazon Bedrock AgentCore Identity to sign Slack users in and read Jira issues through AgentCore Gateway. Set `mode = "vault_gateway"` to use this flow. Identity stores the Cognito refresh token. Your platform handles the browser callback and verifies that the Slack user completing sign-in is the one who started it.

In Slack App Home, choose **Sign in** and follow the browser prompts. Home updates when verification finishes. Open **Tools Consent Portal** to connect your Jira account. **Sign out** closes the local connection. **Sign in again** starts a fresh authorization flow.

When upgrading, set the OAuth scopes your gateway accepts: `scopes` in Vault Gateway mode, or `scope` in portal mode. Run `hermes agentcore doctor` to check whether the current Hermes profile has loaded the plugin and exposes the Jira tool to Slack.

See the [Vault Gateway setup guide](https://github.com/sh1un/hermes-agentcore-plugin/blob/v0.2.0/docs/vault-gateway.md) for configuration and IAM requirements.
